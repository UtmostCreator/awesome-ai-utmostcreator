# Non-Technical Overview

Plain-English explanation for non-technical readers.

## What Is This?

This project is a **starter kit** that teams install into their own software projects. It is
not an app you open and use on its own. Think of it like a box of pre-made settings and helpers
that you drop into a project so that AI coding tools behave consistently and safely.

## What Problem Does It Solve?

Many teams use AI tools to help write and review code, but each tool needs its own setup, rules,
and guardrails. Doing that by hand in every project is slow and easy to get wrong. This kit does
that setup for you, the same way every time, so AI tools start with sensible rules instead of a
blank slate.

## What It Does, In Everyday Terms

- Adds clear written rules that tell AI tools how to work in your project.
- Adds safety rules so AI tools ask before doing risky things.
- Adds small helper programs that check the setup is correct and stays current.
- Helps prepare your project files so AI tools can read them without going over their size limits.

## What It Is Not

- It is **not** an AI model or a chatbot.
- It is **not** a code editor or an IDE.
- It does **not** replace GitHub Copilot, OpenCode, or Claude — it configures them.
- It does **not** make risky, automatic changes to your code on its own.

## Mentor Mode (L0–L5)

The kit can help in escalating layers instead of just handing over an answer, so you learn as
you go. Each rung gives a little more:

- **L0 Frame** — restates the problem and asks what you tried.
- **L1 Probe** — names the concept or pattern that matters.
- **L2 Hint** — points to the file, function, or doc to look at.
- **L3 Scaffold** — gives structure or pseudocode, not the working code.
- **L4 Worked-adjacent** — shows a close example with the key part left for you.
- **L5 Direct solution** — gives the complete answer with explanation.

A "struggle gate" and a quick teach-it-back step help the lesson stick. See the canonical
definition in
[docs/ai/capabilities/mentor-mode/CAPABILITY.md](capabilities/mentor-mode/CAPABILITY.md).

## A Note On What To Expect

This kit is **not** a universal tool that builds and ships software for you. It gives ideas,
scaffolds, prepares, validates, and handles routine work so you can **maintain sanity** — the
result stays in your hands, and human review remains the final authority.

## Who It's For

- Teams that already use (or want to start using) AI coding tools.
- People who want a consistent, safe AI setup across many projects.
- Maintainers who want one place to keep AI rules instead of copying them by hand.
