# Toolchain Requirements

Required tools depend on selected packs. Core full-governance installs require PHP 8.2+, Composer, Bash, Git, jq, ripgrep, fd, and optional context tools such as Repomix and scc.

See `docs/ai/recommended-optional-tools.md` for recommended-but-optional quality/security tooling (mutation testing, link/markdown lint, dependency/secret scanning) not part of the baseline or referenced-tools list.
