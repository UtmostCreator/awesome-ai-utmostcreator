# Agent handoff include — canonical snippet

This is the source of the handoff block that `gen_handoff.py` injects into agent
files (see `dynamic_routing.wire_agents` in `agent-handoff.yaml`). Two ways to use
it:

- **Now (pragmatic):** `handoff/gen_handoff.sh` injects a marker-delimited copy into
  the agent files listed under `wire_agents.targets`. It is idempotent (re-runs
  refresh the block in place) and additive (appended to the end of each file).
- **Durable (correct):** the agent files in `.claude/agents/**` and
  `.github/agents/**` are **generated by the ai-kit installer** from canonical
  templates in `awesome-ai-utmostcreator`
  (`packages/ai-universal-rules/templates/core/agents`). The next installer render
  drops any locally injected block. To make it permanent, add the snippet below to
  the canonical agent template so it renders into every provider adapter.

## Snippet

```md
## Handoff (edgeless, provider-agnostic)

On completion, transfer control with the shared handoff command — do not just
recommend a next agent in prose:

1. Emit a ```handoff``` block: `from`, `goto`, `status`, `contract_id`,
   `payload_ref`, `human_summary`.
2. Validate the transfer: `python handoff/dispatch.py --from <this-agent-id> --goto <target>`.
3. Exit 0 → route to `goto`. Exit 1 → re-emit `goto: orchestrator`,
   `status: blocked`; never force an illegal transfer.

Legal targets and rules: `handoff/generated/HANDOFF-PROTOCOL.md`. The `/handoff`
command runs this flow.
```
