# Control Model

This root file is the short guide version.

See `docs/foundations/CONTROL-MODEL.md` for the maintained canonical copy.

## Practical Summary

- instructions, prompts, agents, and skills are advisory
- hooks, tool limits, and explicit approvals are deterministic
- OpenCode is the stronger explicit-control reference model
- Copilot is a surface-aware adapter model
- do not confuse guidance with enforcement
