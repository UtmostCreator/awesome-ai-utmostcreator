# Optional Delivery Pack

Use this pack when you want a lightweight slice card for non-trivial work.

## Purpose

- Keep planning and review explicit without turning every change into heavy process.
- Keep overhead proportional to risk.
- Separate exploratory prototype work from merge-ready production slices.

## Usage Rules

- Slice cards are optional by default.
- Low-risk slices should stay light.
- Medium and high-risk slices should fill release safety fields.
- Slice size guidance is a warning signal, not a merge gate.

## Included File

- `slice-card.template.md`
