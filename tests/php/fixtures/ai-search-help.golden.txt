ai-search.sh — unified repository search entrypoint

Usage: ai-search.sh MODE [QUERY] [root] [flags]
JSON output: AI_OUTPUT=json

Positionals: MODE [QUERY] [root]

Status values: ok no_matches error unavailable dry_run blocked

Modes:
  Search repository content (query required):
    changed-text     search only unstaged-changed files
    files            filename search (fd; unavailable if fd absent)
    staged-text      search only staged files
    text             search a root (rg)
    tracked          git-grep over tracked files (requires git root)
  Search specific surfaces (query required):
    config           .env*/config/**/*.yaml|yml|json|toml|ini|nix/docker-compose*
    deps             composer/package/lock files, flake.nix, go.mod,
                     Cargo.toml, pyproject.toml
    docs             README*/CHANGELOG*/docs/**/*.md/*.rst/*.adoc
    tests            tests/**/__tests__/**/*.test.*/*.spec.*/*Test.php
  Inspect Git state:
    changed-files    list unstaged-changed files
    staged-files     list staged files
  Inspect Git state (query required):
    diff             unstaged hunks; --staged or --base REF; results carry
                     path/marker/new_line/text/scope
    history          git log pickaxe (-S; --regex -> -G); --messages, --patch;
                     results carry commit/author/date/message/path
  Find maintenance risks (no query):
    todo             TODO|FIXME|HACK|XXX|deprecated|temporary|workaround|legacy,
                     grouped by file with tag/line/text
    unsafe-patterns  curated risky patterns with rule + severity
  Inspect code structure (query required):
    class            class definitions only (symbols[] with kind=class)
    struct           ast-grep pattern; --lang LANG (or AI_LANG, default php)
    symbols          resolve a symbol; emits symbols[]
                     (kind/name/path/start/end/language)
  Diagnose:
    doctor           diagnostics{} of
                     available/missing/warnings/root/git_available
    unsafe-all       approval-gated; always returns status=blocked
  deprecated:
    changed staged  (see Deprecated modes below)

Deprecated modes:
  changed -> changed-files, changed-text
  staged  -> staged-files, staged-text

Env: AI_LANG AI_OUTPUT AI_SEARCH_ENTRYPOINT AI_SEARCH_STRICT PHP_BIN XDG_CONFIG_HOME

Tools:
  primary: ast-grep fd git jq rg
  base utilities: awk cat grep tail
  mode-specific tools: see mode contract via --introspect

Examples:
  AI_OUTPUT=json bash scripts/ai/ai-search.sh text TenantResolver . --fixed
  AI_OUTPUT=json bash scripts/ai/ai-search.sh changed-text Tenant . --fixed
  AI_OUTPUT=json bash scripts/ai/ai-search.sh diff Needle . --fixed --staged
  AI_OUTPUT=json bash scripts/ai/ai-search.sh class UserService . --lang php

See also:
  ai-search.sh doctor          runtime diagnostics (missing tools / root / git state)
  bash scripts/ai/ai-search.sh --introspect   machine-readable contract (modes, flags, output schema)

Machine contract: bash scripts/ai/ai-search.sh --introspect
