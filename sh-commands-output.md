behavior note. No mutating modes (`--apply`, `APPLY=1`, regeneration, installs)

- Generated by: manual read-only probe (`bash <script> --help` or safe mode)

## Legend

- `exit` is the true process exit code (no pipe masking).
- "Read-only" means the safe invocation does not mutate the worktree.
- Findings flagged `[FIX]` are candidates for change; `[OK]` are healthy.

  `WorkerCrashedException ... \\WSL.LOCALHOST\... failed`.

  `php-root-tests` passes **244 tests / 1487 assertions** on PHP 8.5.4.

  when bats is at `/mnt/c/*` / `*.exe` or fails a `--version` smoke check.

  harness is flaky under parallel execution (`SCRIPT_TEST_JOBS=8`). Different
  suites fail on different runs (`query-usage.sh`, `repomix-context-tree.sh`),
  but all pass serially (`SCRIPT_TEST_JOBS=1`) and in isolation (3/3). This is a
